Colorado River Basin Facility Database: Data Dictionary & Schema

Technical entity specifications, measurement units, and authoritative data provenance

1. Database Entity Types

Streamflow Gage (79 facilities): Real-time river reaches monitoring instantaneous discharge rate ($Q$) in cubic feet per second (cfs) via USGS NWIS IV REST service (Parameter 00060).
Storage Reservoir (11 impoundments): Major storage facilities tracking cumulative water volume ($V$) in Acre-Feet (AF) and surface elevation in feet MSL via USBR Upper/Lower Colorado APIs and CDSS.
Trans-Mountain Diversion (4 tunnels): Continental Divide acoustic meters (Adams, Moffat, Roberts, Boustead) exporting water from the Colorado River Basin to Front Range municipal water systems.
Conveyance Canal (4 major conduits): Interstate gravity canals (All-American, Central Arizona Project, Colorado River Aqueduct, Canal Alimentador) routing mainstream Lower Basin deliveries.

2. Field Dictionary & Attribute Definitions

Field Name Data Type Unit Description & Provenance
station_id string — Official 8-digit USGS gage number (e.g. 09380000) or state station code.
reading_num float cfs / AF Current instantaneous streamflow rate (cfs) or reservoir active storage (AF).
norm_cfs float cfs Historical 366-day daily mean streamflow benchmark derived from 50+ year USGS records.
tier_rank integer 1 – 6 Hydrologic Sentinel Tier: 1 (Compact Sentinel), 2 (Basin Sentinel), 3 (Tributary), 4 (Tunnel), 5 (Canal), 6 (Reservoir).
rbi float — Richards–Baker Flashiness Index (Σ|Δq| / Σq). Measures how quickly day-to-day flow spikes and drops.
lat / lon float degrees World Geodetic System 1984 (WGS84) geographic coordinates.

3. Static Geodatabase Files Available for Research

The platform maintains pre-compiled, downsampled JSON matrices for instant static querying without backend database overhead:

  • web/data/live_water_data.json: Real-time observation snapshot for all 92 facilities.
  • web/data/river_network.geojson: 83 continuous river reaches snapped to 0.00m tolerance.
  • web/data/station_hierarchy.json: Sentinel classifications, RBI scores, and coordinates.
  • web/data/replay_7d.json: 170-hour temporal flow replay matrix (81.9 KB).
  • web/data/replay_30d.json: 362-step temporal flow replay matrix (166.4 KB).
