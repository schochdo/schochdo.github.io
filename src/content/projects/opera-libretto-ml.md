An interactive linguistic reading companion and study tool engineered for opera lovers, singers, and language learners.

### Features & Architecture
- **Synchronized Translations**: Dual-column reading interface pairing original German and Italian texts with line-by-line syntax-faithful translations.
- **Linguistic Inspector**: Interactive token-level inspection for lemma, part of speech, literal syntax, and poetic grammatical commentary.
- **In-Browser Audio**: Native German and Italian speech synthesis utilizing the HTML5 Web Speech API.
- **Client-Side Architecture**: Zero-backend single-page application built with React, TypeScript, and Vite.
